## Introduction
This is a React.js single-page portfolio that showcases my background, skills, work experience, education, and projects, with a working contact form for reaching out to me directly.

## Features
- **Hero**: Animated introduction with a typewriter effect cycling through my roles.
- **Skills**: A categorized view of the languages, frameworks, and tools I work with.
- **Experience & Education**: An interactive timeline of my work history and academic background.
- **Projects**: A filterable showcase of my projects with descriptions, tags, screenshots, and links to live demos/source code.
- **Resume**: A direct link to download/view my resume.
- **Contact**: A working contact form (via EmailJS) to send me a message directly from the site.

## Technologies Used
- **React.js** - Core UI library
- **React Router** - Client-side routing
- **styled-components** - Component-scoped styling
- **Material UI (MUI)** - UI components and icons
- **Framer Motion** - Animations
- **Three.js / React Three Fiber / Drei** - 3D visuals
- **EmailJS** - Contact form email delivery
- **react-vertical-timeline-component** - Experience/Education timeline
- **typewriter-effect** - Animated hero text

## Installation
To run this portfolio locally, follow these steps:

1. Clone the repository: `git clone https://github.com/rakesh81004/My-Portfolio---Rakesh-S-P.git`
2. Navigate to the project directory: `cd My-Portfolio---Rakesh-S-P`
3. Install the dependencies: `npm install`
4. Start the development server: `npm start`
5. Open your browser and visit: `http://localhost:3000`

## Usage
After installing and running the project locally, you can navigate through the different sections of the portfolio using the navigation menu. Explore the Skills and Experience sections to learn about my background, browse the Projects section for details on my work, and use the Contact section to send me a message.

## Deployment
This project is deployed on [Netlify](https://www.netlify.com/) and is connected to the `main` branch of this repository — every push to `main` automatically triggers a new deployment.
